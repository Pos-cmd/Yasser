# yas.xyz

My personal site. I rebuild it roughly once a year, which is a habit I have made peace with — it is the cheapest way I know to test whether a new tool or idea is worth keeping.

## Constraints I set myself

- Content lives in Markdown files, not in a database, so it survives any frontend rewrite.
- No analytics, no cookie banner, no third-party script that slows the first paint.
- Everything visible is achievable with plain CSS and a handful of components. No animation library.

## Current state

Nuxt 4 with Nuxt Content for the writing and Nuxt UI for the primitives, styled with a small set of design tokens. The whole thing builds to static files and is served from an edge network.
