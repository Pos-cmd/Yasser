# About

I'm Yasser, a 26-year-old developer based in France. I got into code the way most people do — by breaking things and wanting to understand why they broke — and I never really stopped.

Today I mostly build web applications. My favourite part is the moment a vague idea turns into something people actually use, and I like it even more when the code underneath is still readable six months later.

## How I got here

I started with small static sites, moved into full-stack work with PHP and Laravel, then gradually shifted toward the Vue and Nuxt ecosystem. Somewhere along the way TypeScript stopped feeling like a constraint and became the thing that makes a growing codebase bearable.

I've worked on client projects, internal tools and a few products of my own. The common thread is that I enjoy owning a feature end to end — from the data model to the last pixel of the empty state.

## How I work

- **Small steps, working software.** I'd rather ship something narrow that runs than something broad that doesn't.
- **Readable over clever.** Code is read far more often than it's written, including by future me.
- **Boring tools, sharp edges.** I pick stable, well-documented technology so the interesting problems stay in the product instead of the plumbing.
- **Curiosity as a method.** I start a lot of side projects. Most go nowhere, but a few are the reason I learned something worth keeping.

## Outside the editor

I read a lot of manga, I try to work out regularly, and I'm usually halfway through some experiment. The things that aren't code live on the [shelf](/shelf).
