# Senior Frontend Developer at Lumina Studio

I joined a small product team to rebuild a client dashboard that had grown organically for years and was becoming hard to change. My focus was the frontend architecture and the design system that sits underneath it.

## What I worked on

- Rewrote the dashboard from Vue 2 Options API to Vue 3 `<script setup>`, which cut the average component in half while making the data flow far easier to follow.
- Built a shared component library on top of Nuxt UI, documented so that designers and developers were finally arguing about the same thing.
- Introduced Vitest and Playwright for the flows that broke most often — authentication, billing and exports.
- Ran the frontend side of the migration to a typed API client, which removed an entire category of runtime bug.

## What I learned

That most "frontend problems" are actually naming problems. Once the domain vocabulary was settled, half the tickets in the backlog turned out to be duplicates of each other.
