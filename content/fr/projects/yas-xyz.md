# yas.xyz

Mon site personnel. Je le reconstruis à peu près une fois par an, une habitude avec laquelle j'ai fait la paix — c'est la façon la moins chère que je connaisse de tester si un nouvel outil ou une idée vaut la peine d'être gardée.

## Les contraintes que je me suis fixées

- Le contenu vit dans des fichiers Markdown, pas dans une base de données, pour survivre à n'importe quelle réécriture du front-end.
- Pas d'analytics, pas de bandeau cookies, pas de script tiers qui ralentit le premier affichage.
- Tout ce qui est visible est réalisable en CSS simple et avec une poignée de composants. Aucune librairie d'animation.

## État actuel

Nuxt 4 avec Nuxt Content pour l'écriture et Nuxt UI pour les primitives, stylé avec un petit jeu de tokens de design. L'ensemble se construit en fichiers statiques et est servi depuis un réseau de périphérie.
